# velocity

Created in [T3 Code](https://t3.codes).

## Development

Windows 11 is the primary platform. Install the Visual Studio C++ build tools,
WebView2, rustup, Node.js 24 and pnpm 10.34.9. Rust 1.99.0 is pinned in
`rust-toolchain.toml`. Install the Tauri v2 CLI with
`cargo install tauri-cli --version 2.11.4 --locked` if it is not already available.

From the repository root:

```powershell
pnpm -C ui install --frozen-lockfile
cargo tauri dev
```

Tauri starts and stops the Vite development server. Run `cargo tauri dev` by
itself; the frontend development server must not be started separately.

The first M1 shell supplies the opaque black frameless window, draggable title
bar and native minimize, maximize/restore and close controls. The main workspace
is empty until the subsequent layout milestone. Native resize/focus events keep
the maximize button in sync with OS window changes. No simulated project or
agent state is included in the shell.

Frontend commands and events are generated by `tauri-specta`. After changing the
Rust IPC contract, run `pnpm -C ui bindings` and commit the generated
`ui/src/lib/bindings.ts`. Components access that contract through `ipc.ts`.
Event payloads and name constants are generated from Rust; `ipc.ts` wraps
Tauri's typed listeners because the upstream generated event helpers use `any`.

```powershell
cargo fmt --all
pnpm -C ui format
cargo build --workspace
cargo clippy --workspace --all-targets -- -D warnings
pnpm -C ui build
pnpm -C ui check
pnpm -C ui lint
```

Build and lint run in GitHub CI on Windows. Proofs run locally before pushing;
see [the proof toolchain instructions](proofs/README.md). Scouts and PR duty own
tests and stress scripts.
