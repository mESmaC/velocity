#### §3.1 · F6 IPC

- **command**
  - `list_pull_requests { project_identifier }`,
  - `get_pull_request { project_identifier, number }`

GitHub through signed-in `gh` supplies paginated snapshots for legacy PR threads.

F6 observes same-repository PRs by the thread's immutable branch, including a PR closed or merged between observations.
An open draft claim leaves its thread working until the PR is marked ready; a closed draft still reports closure.
The native watcher checkpoints its history and pending agent notifications in `state.json`, queues changed CI/review/conflict information at agent step boundaries, and publishes the thread lifecycle.
Closing preserves the checkout and branches; confirmed merges stop the agent and remove its verified registered worktree through the existing F5 lifecycle plan, retrying cleanup errors.
Before forced removal begins, the watcher durably records `worktree_removal_started` next to `worktree_deleted` in `state.json`, after the F17 deletion gate verifies ownership and absence of uncommitted, untracked or unpushed work.
Only that record permits retrying an unregistered leftover folder, and only while it contains no `.git` entry and does not contain the project checkout; an unregistered folder without that record is kept.

- **command**
  - `watch_rosen_status { project_identifier }`

Starts the selected project's Rosen status subscription and cancels the previous one.
A null identifier stops the subscription when no project is selected.
The command returns whether the selected project uses Rosen.

- **command**
  - `run_rosen_thread_action { project_identifier, thread_identifier, change, action }`

Validates the owning thread and its current Rosen change before running Name with a message, Rebase, Abandon or Resolve.
Workspace mutations run at an agent turn boundary.
Resolve saves a conflict handoff for the agent and checks for open conflicts again before delivery.
The change track, land history and sidebar stage arrive in the existing layout snapshot.

- **command**
  - `open_project_pull_request { project_identifier, number }`

Opens a legacy AIRC PR link in its owning thread or in the browser.
The command validates that the requested project is selected.

- **event**
  - `pr://opened`,
  - `pr://ci`,
  - `pr://review`,
  - `pr://merged`,
  - `pr://closed`

F6 lifecycle snapshots: project/thread identifiers, PR number, stage and worktree-deleted status.
`pr://merged` follows successful worktree cleanup; the watcher retains the legacy review history.

- **event**
  - `rosen://status`

Publishes an initial status snapshot and updates from Rosen for the selected project, including owning thread links and reconnect errors.
The UI filters incoming snapshots by project identifier.
