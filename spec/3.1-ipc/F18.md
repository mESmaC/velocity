- **command**
  - `generate_design_system { project_identifier, regenerate }`; `details` on each `get_skill_settings` card

built-in pack specifics (F18).
`generate_design_system` runs UI UX Pro Max's `search.py --design-system --persist` (with `--force` on Regenerate) in the main checkout, queried from SPEC.md's opening sentence, then commits `design-system/<project>/` and, while MASTER.md exists, the AGENTS.md rule under `## UI`, each on its own.
Each card's `details` carries UI UX Pro Max's design system row (while installed, for a project) and REA's shared MCP server (while always on); Game dev skills' engine line is the project scan's (F18 Suggestions).
Bundle chips count the skills each bundle's folders hold at the pinned commit; folders the pack tracks as git links are mirrors and never count or link twice.
Every `session/new` adds the always-on packs' MCP servers after Settings → Agents' shared servers, keeping any agent-owned entry of the same name.
The composer lists installed skills machine-wide, and each turn resolves its skill references against the current pinned library.
