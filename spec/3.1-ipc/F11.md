F11 outliner: read the checkout's real AGENTS.md, apply section/rule and structural keyboard edits in Rust, and save/commit only that file.
Snapshots include the exact Markdown, rule count, dirty state and focus target.
Unsupported Markdown is preserved verbatim.
Saving rejects external changes and keeps the draft; Discard draft and reload explicitly replaces the draft with the current disk file without writing or committing.
Reload failures keep the draft.
A failed commit or push can be retried.
Remote projects fetch and merge the base without rewriting history before pushing; a conflict names the files and stops publication, and a rejected push keeps the local commit for retry.
Local projects without origin keep local commits.
The default AGENTS.md template uses the same publication path.
Snapshots also carry each rule's live lint marks (hedge, modal, vague; never inside inline code), the Flagged list and the Covers checklist; `AddCoverage { item }` inserts a missing topic's bullets after the last rule of its section, or in a new section at the end.
