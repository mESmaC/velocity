#### §3.1 · 3.2 IPC

<!-- split-spec IPC row -->
- **command**
  - `edit_shared_mcp_servers { edit }`

Settings → Agents → shared MCP servers (§3.2 Tool access).
`Add { name, target }` reads `target` as an `http://` or `https://` URL, or else as a command line; `Remove { name }` drops one.
Names use letters, digits, `-` and `_`, are unique ignoring case, and may not start with `velocity` (Velocity's own servers).
Returns the saved list, which `get_settings` also carries as `agents.shared_mcp_servers`.

<!-- split-spec IPC row -->
- **command**
  - `get_collapse_connection`

Settings → Agents → Shared MCP servers → Collapse (§3.2 Tool access, #430).
Returns `{ account, enabled, name, url }`: the connected Collapse account or `null`, the switch, and the server's name and URL as agents see them.
The tokens never reach the window.

<!-- split-spec IPC row -->
- **command**
  - `connect_collapse`

Opens Collapse's desktop sign-in in the browser and resolves once the owner approves, with the tokens saved to the OS credential store.
Refused while another sign-in is waiting, and after ten minutes without an approval.
Returns the same value as `get_collapse_connection`.

<!-- split-spec IPC row -->
- **command**
  - `disconnect_collapse`

Forgets the Collapse tokens on this machine and returns the same value as `get_collapse_connection`.

<!-- split-spec IPC row -->
- **command**
  - `set_collapse_mcp { enabled }`

Saves the switch as `agents.collapse_mcp`, which new agents read; returns the same value as `get_collapse_connection`.
