- **command**
  - `edit_shared_mcp_servers { edit }`

Settings → Agents → shared MCP servers (§3.2 Tool access).
`Add { name, target }` reads `target` as an `http://` or `https://` URL, or else as a command line; `Remove { name }` drops one.
Names use letters, digits, `-` and `_`, are unique ignoring case, and may not start with `velocity` (Velocity's own servers).
Returns the saved list, which `get_settings` also carries as `agents.shared_mcp_servers`.
