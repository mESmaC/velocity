- **command**
  - `get_code_graph { project_identifier }`,
  - `set_code_graph { project_identifier, enabled }`,
  - `reset_code_graph_usage { project_identifier }`,
  - `graph_status { project_identifier }`,
  - `retry_graph_index { project_identifier }`

The usage modal's Code graph section (F19 Measuring it): the project's switch and the comparison of its graph-on and graph-off totals, worked out in Rust.
`set_code_graph` applies to agents started afterwards; `reset_code_graph_usage` clears both sides' totals and the tool and thread counts and starts counting again.
The first three commands return the switch and on/off comparison.
`graph_status` returns the active project's graph health, coverage, freshness, cache and usage and schedules an index of an outdated base when the graph is on.
`retry_graph_index` schedules a new attempt for the current base and returns the status view.
