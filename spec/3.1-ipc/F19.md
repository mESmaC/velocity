- **command**
  - `get_code_graph { project_identifier }`,
  - `set_code_graph { project_identifier, enabled }`,
  - `reset_code_graph_usage { project_identifier }`

The usage modal's Code graph section (F19 Measuring it): the project's switch and the comparison of its graph-on and graph-off totals, worked out in Rust.
`set_code_graph` applies to agents started afterwards; `reset_code_graph_usage` clears both sides' totals and starts counting again.
Each returns the section's new view.
