- **command**
  - `get_proofs_settings { project_identifier }`

Settings → Proofs (F13, F17), read from the project's checkout without building: SPEC.md's proof list (a `Proof list` heading, or the list under a line ending `proof list:`), each tracked `proofs/<Feature>/Design.lean` with the level each language reaches, each language's code-level translator and strongest level, and the stress-diff input count.
The count is saved with `set_settings`; scout sweeps diff at least that many inputs per feature against its compiled model.
