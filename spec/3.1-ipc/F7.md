- **command**
  - `get_duty_dialog_defaults`,
  - `get_duty_agent_transcript { nickname }`,
  - `start_duty { request }`,
  - `pause_duty { request }`,
  - `add_duty_agents { request }`,
  - `dismiss_duty_agent { request }`,
  - `stop_duty { request }`

Review view, start dialog defaults, start/pause/resume, add agents, dismiss agents and stop Scouts or the review swarm, persisted on the project in `state.json` and broadcast over `duty://event`.
`get_duty_agent_transcript` returns a review swarm worker's transcript for this app run, including session boundaries (F7, #456).

- **event**
  - `duty://event`,
  - `swarm://event`

activity feeds.
`swarm://event` carries the project and swarm identifiers and one feed line (time, actor, kind, message); the swarm view itself arrives on `layout://state` as `active_swarm`.
