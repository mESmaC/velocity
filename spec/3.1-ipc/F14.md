#### §3.1 · F14 IPC

<!-- split-spec IPC row -->
- **command**
  - `set_airc_message_mode { project_identifier, nick, mode }`

Set Open, HeadsDown or Quarantined from the AIRC nick list.
Modes persist in the channel log; quarantine freezes claim extension and release.

<!-- split-spec: {"order":176,"kind":"ipc","indentation":0} -->
<!-- split-spec IPC row -->
- **command**
  - `airc_send { project_identifier, text }`

Your F14 comment in a registered project channel.
An exact `nick:` prefix targets that member.
A single-word prefix that is a likely mistyped nick (a nick that left, or one within two character edits of a joined nick, ignoring case) is rejected with the closest nick named.
Every other comment broadcasts to active thread members, including one that starts with an ordinary word and a colon.
Delivery uses ordinary queued steering and never cancels a running turn.

<!-- split-spec: {"order":177,"kind":"ipc","indentation":0} -->
<!-- split-spec IPC row -->
- **command**
  - `get_airc_modal { project_identifier }`

The F14 AIRC modal's view, built in Rust from the active project's channel and saved thread and duty state: tab counts (Claims adds its overlap count), tagged and toned event rows, messages with mentions of you, the claims board with overlapping files of working and PR-open agents, both ledgers, and the grouped nick list.
`A`, the palette and the footer link open the modal through `dispatch_layout` (`airc_open` on `layout://state`); `Esc` closes it.
Comments go through `airc_send`.

<!-- split-spec IPC row -->
- **command**
  - `airc_events { project_identifier, after }`,
  - `airc_messages { project_identifier, after }`,
  - `airc_send`,
  - `airc_claims`,
  - `airc_claim`,
  - `airc_release`,
  - `airc_share`,
  - `airc_wait`,
  - `airc_ledger { project_identifier, ledger, after }`

AIRC (agents get the same as MCP tools).
`airc_events` returns only F14 event log entries (`EVENT_TAGS`, including `discovery` notices); `airc_messages` returns only agent messages and user comments; `airc_ledger` reads `discovery` or `past_work`.
`airc_claim` is atomic: it returns `granted`, or `refused { holder, since }`

<!-- split-spec IPC row -->
- **event**
  - `airc://modal`

The active project's AIRC modal view, published only while the modal is open and when it changed.
Agents write the channel from their own MCP processes, so Velocity reads it once a second.
Lines are marked read while the modal is open; the footer unread badge (amber when an unread line is an overlap or a failure) arrives on `layout://state`.
