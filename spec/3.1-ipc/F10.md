- **command**
  - `get_swarm_dialog { query }`,
  - `launch_swarm { request }`,
  - `add_to_swarm { request }`

Swarm (F10).
`get_swarm_dialog` draws the dialog in Rust from the user's choices: source counts, open items (taken items and draft tasks shown but unselectable), launchable models with the round-robin split, the PR duty capacity offer and the footer.
`launch_swarm` checks the launch gate afresh, records the swarm on the project in `state.json`, then for each item atomically adds a member thread on `vel/<task-slug>` or `vel/issue-<n>` (a task becomes Now with its thread) and starts its worktree and ACP agent; `add_to_swarm` does the same into an existing swarm.
Optionally starts or tops up PR duty.
Members are ordinary threads: a member's merge marks its task done, and the other members whose changed files overlap the merged PR's files get a queued rebase notice.
A message from the swarm composer is queued to every working or in-review member.
