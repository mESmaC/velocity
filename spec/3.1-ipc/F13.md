- **command**
  - `get_settings`,
  - `set_settings`

Settings includes the saved, default-off agent preference `agents.context_handoff` for new Rosen work items (#467).

- **command**
  - `get_ui_zoom`
  - `adjust_ui_zoom { adjustment }`

Appearance returns the saved UI zoom percentage and the available adjustments.
Increasing, decreasing and resetting zoom update the same application-wide preference.
