#### §3.1 · F20 IPC

- **command**
  - `open_browser_view { project, thread }`

Opens the live view for an implementation thread and returns its view identifier, ownership and tabs.

- **command**
  - `close_browser_view { project, thread, view }`

Hands back control and stops streaming frames for the view.

- **command**
  - `take_over_browser { project, thread, view }`

Pauses agent browser calls and enables owner input for this view.

- **command**
  - `hand_back_browser { project, thread, view }`

Returns control to the agent and queues a notice with the current page and tab state.

- **command**
  - `browser_input { project, thread, view, tab, input }`

Sends click coordinates, a key, text or a wheel scroll to the current tab during owner control.

- **command**
  - `switch_browser_tab { project, thread, view, tab }`

Switches to the selected tab during owner control.

- **event**
  - `browser-frame { project, thread, view, frame }`

Carries the current tab and ownership state and an optional downscaled JPEG with viewport dimensions.
