- **command**
  - `get_continuous_dispatch { project_identifier }`,
  - `set_continuous_dispatch { project_identifier, slots, paused }`

F8 per-project continuous dispatch settings and Duty projection: slot count, busy count, pause state, next five issues and source errors.
Rosen projects only; ownership and attempted issue version are saved atomically before the ordinary background thread launch.

<!-- split-spec: {"order":161,"kind":"ipc","indentation":0} -->
<!-- split-spec IPC row -->
- **command**
  - `add_task { project_identifier, title }`,
  - `list_tasks { project_identifier }`

F8 project Task List.
Adding saves a user-attributed draft before lock or todo after lock, without changing SPEC.md.
The add input and `/task` use the same store path through `dispatch_layout`.
`layout://state` carries per-task states, owning-thread status and attribution links.
