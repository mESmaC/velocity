- **command**
  - `get_continuous_dispatch { project_identifier }`,
  - `set_continuous_dispatch { project_identifier, slots, paused }`

F8 per-project continuous dispatch settings and Duty projection: slot count, busy count, pause state, next five work items, source errors and an `integration_notice` for a base the integration build has not covered within its limits (#503) and for landed issues past the integration wait limit.
Rosen projects only; ownership, launch origin and any attempted issue version are saved atomically before the ordinary background thread launch.

<!-- split-spec IPC row -->
- **command**
  - `add_task { project_identifier, title }`,
  - `list_tasks { project_identifier }`,
  - `undo_task_event { project_identifier, request }`

F8 project Task List.
Adding saves a user-attributed draft before lock or todo after lock, without changing SPEC.md.
The add input and `/task` use the same store path through `dispatch_layout`.
`layout://state` carries per-task states, owning-thread status and attribution links.
For Rosen projects, the same event carries the saved Work projection, per-issue expansion and manual task completion times.
Undo takes the request identifier from an AIRC Events row and restores its saved task while that change is current.

- **command**
  - `get_work_change { project_identifier, change }`

Read the owner and current head of the Rosen change linked from a Work row.
