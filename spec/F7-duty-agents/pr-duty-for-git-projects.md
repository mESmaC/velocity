#### PR duty · For git projects

- **For git projects** (#381).
  A Rosen project that sets `review = "after-land"` has no approval for PR duty to give (§1 Rosen rules): the Duty dialog doesn't offer PR duty there and says why, and Velocity lands its changes with no PR duty agent (A Rosen change, below).
  An existing PR duty role on such a project reviews only its GitHub PRs.
  Review, scouting and Lean follow the land without blocking it (#382, §1 Rule 8).
  A Rosen project that keeps `review = "before-land"` keeps PR duty as below.
