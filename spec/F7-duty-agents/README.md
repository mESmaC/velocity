### F7 · Duty agents

Long-running roles.
They appear under **On duty**, with an agent count (×N) and a one-line summary.
Start one from the home chips (`V`, `S`), the palette, or the + on the group.
The start dialog sets role, number of agents (1–4), model, effort, speed and role-specific rules.
Its model cards are every signed-in provider's model, starting on the default for new threads, and Speed starts at Settings' default.
Effort starts at Role default, which reads Settings → Agents for each session (F15).
An explicit effort and the selected model and speed apply to each session that agent runs.
An agent saved before effort and speed could be chosen uses Settings' defaults.
Starting a role that already exists adds agents to it; agents already on the role keep their own model.
