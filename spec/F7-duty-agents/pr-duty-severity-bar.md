#### PR duty · Severity bar

<!-- split-spec: {"order":1044,"kind":"markdown","indentation":0} -->
- **Severity bar** (locked).
  A finding blocks a merge only for: data loss or corruption, a crash or hang, a §1 rule violation, a security hole, a failing local check, or the main path of the claimed piece not doing what its SPEC.md section says.
